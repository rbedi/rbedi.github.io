On writing a first post

July 6, 2026

This is an example post. It exists to show what the formatting looks like — paragraphs, headings, links, lists, images, quotes, and endnotes.1

Body text is set in a serif for comfortable reading, with a generous line height and a narrow measure so lines never get too long. You can bold things, add emphasis, highlight a phrase, drop in inline code, or link out to a source.

A section heading

Sections break up longer pieces. Headings use the same serif as the body to keep everything feeling like one document.

A block quote for pulling out a passage or citing someone at length. It sits slightly muted and indented from the main column.
